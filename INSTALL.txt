Smart Filter v3.6.0 安装说明

v3.6.0 是企业落地第一批（合规、数据保管、评测集工具、维护）。26 个岗位的设置不变，只有打招呼每日总上限改成 180：
· 解压 SmartFilter-v3.6.0.zip 覆盖原文件夹，在扩展页点「重新加载」，版本显示 3.6.0，再刷新已打开的 BOSS / 猎聘页面
· 打招呼每日总上限：原来是 200 或 50 的自动改成 180。需要更多到「打招呼 · 每日总上限」改，超过 180 会提示
· 智选判不合格的人先放进浮层「待确认」标签，点「确认拒绝」才发拒绝话术，点「改为合格」就不拒绝
· 第一次打开工作台，顶部会提醒登记影响评估、做全量备份。到「设置 · 合规」登记，到「设置 · 备份与恢复」设备份密码、做一次全量备份，再勾上「每天自动备份」
· 人才库里同一个人会合成一条（每个岗位一条投递记录）。觉得合错了，到「设置 · 合规」点「撤销合并」
· 卸载插件会清空本机全部数据，卸载、换电脑前先做一次全量备份
· 平台改版、候选人要求删除信息、换电脑的处理步骤见源码包里的 docs/RUNBOOK.md


v3.5.0 打招呼改成岗位一一对应：工作经历里有一段的方向就是正在招的岗位才打招呼，方向不一样的（例如招 IC 验证，做数字 IC 设计的）不再打招呼。26 个岗位的设置不变：
· 解压 SmartFilter-v3.5.0.zip 覆盖原文件夹，在扩展页点「重新加载」，版本显示 3.5.0，再刷新已打开的 BOSS / 猎聘页面
· 建议先用「试运行」跑一个岗位，看浮层上每段工作的标记（本岗位 / 同方向 / 不是这个岗位），确认没问题再正式运行


v3.4.0 岗位知识库可以自己加、删方向，评测集改成每个岗位标到 111 张才算稳定。26 个岗位和判断规则都不变：
· 解压 SmartFilter-v3.4.0.zip 覆盖原文件夹，在扩展页点「重新加载」，版本显示 3.4.0，再刷新已打开的 BOSS / 猎聘页面
· 新增方向：「设置 → 岗位知识库 → 新增方向」，填名称、大类、叫法（逗号隔开）、相近方向（选填），点「加到知识库」
· 删除方向：表格每行最右边「删除」，在弹出的气泡里点「确定」。内置的方向删了，在表格下面点「恢复」就回来了

安装（数据不会丢）
1. 打开 chrome://extensions/（Edge 是 edge://extensions/），右上角「开发者模式」打开
2. 找到你现在一直在用的那张「Smart Filter」卡片（岗位、人才库数据都存在它里面），点卡片上的「详细信息」看它的「来源」文件夹
3. 把本压缩包解压出来的全部文件复制进那个文件夹，覆盖原文件，回到扩展页在这张卡片上点「重新加载」，版本显示 3.1.0 即可
   不想覆盖的话：先在原插件「设置 · 备份与恢复」点「导出全部设置」，再「加载已解压的扩展程序」选本文件夹，装好后「导入设置文件」。注意这种方式人才库记录不会带过来
4. 其他「Smart Filter」卡片（v2.1.0、v1.10.x 等）点「移除」或关掉开关，只留一个在用
5. 刷新已经打开的 Boss直聘 / 猎聘 页面
RPA 助手不用重装。

一、更新插件
1. 用本版全部文件覆盖原插件文件夹（包含 manifest.json 的那一层）。岗位、设置、人才库都在浏览器里，不会丢
2. 打开 edge://extensions/ 或 chrome://extensions/，在「Smart Filter」卡片上点「重新加载」
3. 刷新已经打开的 Boss直聘 / 猎聘 页面
4. Boss 推荐牛人页的打招呼浮层显示「v1.10.0」和「执行方式：RPA 真实鼠标键盘」即成功

二、安装 RPA 助手（只做一次，需要电脑上有 Python 3）
1. 在资源管理器里打开插件文件夹里的 rpa-helper 文件夹
2. 点窗口上方的地址栏，把路径删掉，输入下面这行，按回车：
      cmd /k py install_autostart.py
   · 提示「'py' 不是内部或外部命令」：把 py 换成 python 再试
   · 都不行：说明还没装 Python，先到 python.org 安装（第一页勾选 Add python.exe to PATH）
   · 也可以在 编辑器终端 里打开 rpa-helper 文件夹，在下方「终端」里输入 python install_autostart.py
   · 不要双击 .py 文件（电脑上 .py 默认用编辑器打开，双击不会运行）
3. 看到「RPA 助手已在后台运行」就装好了。以后开机自动在后台运行，没有窗口
4. 到 侧边栏底部「设置」· Boss 执行方式（RPA），点「检测连接」，显示「已连接 RPA 助手 v1.0.2」即通
5. 插件文件夹挪了位置，要重新做一次第 2 步
6. 之前装过 v1.9.2 的 RPA 助手（开机自启）：在新的 rpa-helper 文件夹里重新做一次第 2 步，开机自启会改指向新位置

三、运行时注意
1. RPA 用的是真鼠标真键盘：运行时 Boss 窗口会被切到最前面，鼠标会自己动
2. 你一动鼠标或键盘，RPA 立即让位，停手 8 秒后（设置里可改）自动接手，不会判失败、不会跳人
3. 屏幕锁定时 RPA 不能操作，会每分钟重试，解锁后自动继续。计划任务在半夜跑，请把电脑设成不锁屏、不睡眠
4. 打招呼和智选同时开着时，两个页面轮流用鼠标，不会抢
5. 浏览器不要用「以管理员身份运行」，否则 Windows 会拦下 RPA 的鼠标键盘

四、出问题时
1. 浮层写「连不上本机 RPA 助手」：助手没在运行，按第二部分重新安装
2. 浮层写「页面没收到鼠标位置」或「校准后仍没落在目标上」：在 rpa-helper 地址栏输入 cmd /k py diag_rpa.py 回车，脱敏后提交 GitHub Issue
3. 浮层写「浏览器拦下了到本机 RPA 助手的连接」：扩展管理 → Smart Filter → 详细信息 → 网站设置 → 本地网络访问 → 允许
4. 临时退回旧版：侧边栏底部「设置」· Boss 执行方式 选「脚本点击（旧版）」，不用重装
5. 停掉后台助手：cmd /k py stop_rpa_helper.py。取消开机自启：cmd /k py remove_autostart.py
6. RPA 助手的操作日志在 rpa-helper\rpa-helper.log
