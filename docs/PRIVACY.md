# 隐私政策

**生效日期**：2026-11-08 ｜ **适用版本**：Smart Filter 3.6.0
**联系渠道**：GitHub 仓库 [Security → Report a vulnerability](https://github.com/Bink-citl/-smart-filter-extension/security/advisories/new) 或 [Discussions](https://github.com/Bink-citl/-smart-filter-extension/discussions)

本页可发布到 GitHub Pages 后作为 Chrome 网上应用店的「隐私政策 URL」，也可作为企业法务/安全评审材料。

## 1. 我们收集什么

### 1.1 默认模式（无需账号、无服务端）

扩展在**您的浏览器本机**处理并保存：

| 数据 | 来源 | 存放位置 | 用途 |
|---|---|---|---|
| 岗位描述与筛选条件 | 您手动输入，或从招聘页面读取您正在查看的职位 | `chrome.storage.local` / IndexedDB | 生成匹配评分 |
| 候选人卡片信息与在线简历文本 | 您主动启用功能时从招聘页面读取 | 本机 | 匹配判定、生成决定记录 |
| 简历文件（PDF / DOCX / 图片） | 您主动下载或拖入 | 本机 + 您指定的本地文件夹 | 解析、命名、归档 |
| 决定记录、运行记录、评测样本 | 扩展运行产生 | 本机 | 审计、统计、规则评测 |
| 设置与话术模板 | 您填写 | 本机 | 功能配置 |

**项目维护者不运营任何服务端，无法访问、也不会接收上述数据。**

仓库内 `data/preset-backup.json` 为**虚构示例数据**（示例公司「示例科技（Example Tech）」+ 26 个示例岗位），不含任何真实个人信息。

### 1.2 可选：AI 判断（默认关闭）

在设置中主动开启并自行填写第三方接口与密钥后，扩展会把**岗位说明与简历文本片段**直接发送到**您配置的端点**：

- 发送前按代码逻辑去除姓名、手机号、座机、邮箱、微信号、身份证号；请自行验证效果。
- 端点、密钥与每日调用上限由您控制；维护者不经手、不存储、不代理。
- 关闭后全部本地功能仍可用。
- 商店「数据使用声明」须如实勾选「用户提供的文本会传输至用户自配的第三方端点」，**不得**勾选「不收集任何数据」。

### 1.3 可选：本机 RPA 助手（默认不安装）

自动化执行能力依赖一个**由用户手动安装、仅监听 `127.0.0.1`** 的本地 Python 助手：

- 通过本机回环端口（默认 17861）接收本扩展指令，校验自定义请求头与扩展来源，不对外网开放。
- 安装脚本写入当前用户开机启动项（`HKCU\...\Run`），以无窗口方式后台运行；`stop_rpa_helper.py` 与 `remove_autostart.py` 可随时停止并取消自启。
- 在本机模拟鼠标/键盘操作，作用范围限于您指定的招聘网站标签页；日志写入本机 `rpa-helper.log`。
- 助手不上传数据。企业环境请先经 IT / 安全部门评估（开机自启 + 本地监听端口 + 输入模拟属常见受管控行为）。

### 1.4 页面内脚本注入

内容脚本在招聘站点读取页面文本并展示浮层；其中一项能力在页面主环境（`MAIN` world）临时接管 `window.open` 与链接点击，把新标签地址交给扩展后台打开。该行为仅在您主动触发职位抓取期间启用，不修改页面持久化数据，不读取与功能无关的内容。

## 2. 使用目的

**单一用途**：辅助招聘人员完成简历筛选与决策留痕。数据用于本地解析与匹配、生成可解释决定记录、生成您主动请求的报表与导出、以及您主动启用的自动化操作。不用于广告、画像、模型训练或任何无关目的。

## 3. 共享与披露

不出售、不出租、不与任何第三方共享。维护者不持有您的数据，若收到法律要求也因不持有而无法提供。

## 4. 存储、保留与删除

| 数据 | 默认保留 |
|---|---|
| 运行记录 | 7 天 |
| 自动决定明细 | 90 天 |
| 月度汇总（仅数字） | 3 年 |
| 不合适 / 未沟通候选人 | 180 天 |
| 已收简历未面试 | 1 年 |
| 面试 / 录用 | 不自动删 |

- 存储位置：安装扩展的浏览器本地配置与您指定的本地文件夹。
- 提供全量加密备份（`.sfbak`）与恢复，以及「按要求删除」一次性清除某候选人在扩展内的全部信息。
- 卸载扩展会清除本机全部数据，请先备份。
- 评测样本采集可在设置中关闭，导出前二次去标识。

## 5. 权限说明（与 manifest.json 逐项对应）

| 权限 | 用途 |
|---|---|
| `storage` / `unlimitedStorage` | 本地保存岗位、候选人、设置、决定记录与简历元数据 |
| `downloads` | 导出报表与按规则命名保存简历 |
| `tabs` / `scripting` | 定位招聘网站标签页并注入浮层与读取脚本 |
| `alarms` | 计划任务与保留期限每日检查 |
| `offscreen` | 在离屏文档解析 PDF 文本 |
| `debugger` | 在部分执行模式下通过 CDP `Input` 域发送真实鼠标事件 |
| `management` | 查找/唤起配套工作台扩展（标识见 `docs/OPEN_SOURCE_NOTE.md`） |
| `host_permissions`（招聘站域名） | 仅在这些站点读取页面内容 |
| `http://127.0.0.1/*` | 与本机 RPA 助手回环通信 |
| `optional_host_permissions` | 仅当您主动授权自定义 AI / 配置端点时按需申请 |

逐项提审理由见 `PERMISSION_JUSTIFICATION.md`。

## 6. 自动化决策与人在回路

- 评分与判定为**辅助建议**，输出逐项依据（命中条件、规则版本、判定原因），可人工复核。
- 不合格默认进入「待确认」，由 HR 确认后才执行后续动作；不自动作出淘汰决定。
- 每判定一人生成一条可导出的决定记录，便于申诉与审计。
- 评分维度不含性别、年龄、婚育、民族、宗教、籍贯等受保护属性；示例数据不预置年龄与第一学历硬门槛。使用者若自行配置，需自行承担合规责任。
- 最终录用决定必须由人工作出。详见 `MODEL_CARD.md`。

## 7. 儿童隐私

面向企业招聘人员，不面向儿童。

## 8. 您的权利

可随时查看、导出、修改、删除本机全部数据；卸载即可清除。隐私疑问请通过上述渠道联系。

## 9. 政策变更

数据处理方式发生变化时，会在新版本中显著提示并更新本页生效日期后再发布，不在静默更新中改变数据实践。
